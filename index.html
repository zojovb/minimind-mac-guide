“2 小时训出自己的模型”，
放到你的 Mac 上要多久？

先猜一下：作者说用一张显卡 2 小时就能训完。你的 MacBook Air 没有那种显卡，从零训一个同样的模型，要多久？
看答案

约 130 小时，5 天多，这还只是第一阶段“预训练”。

我在你电脑上用一小份数据（15MB）实测：训完一遍用了约 48 分钟。作者推荐的入门数据有 1.2GB，是它的 80 倍，默认还要训 2 遍。48 分钟 × 80 × 2，粗算 130 小时左右，后面的“对话训练”阶段还没算。MacBook Air 没有风扇，连续跑几天会越跑越慢。

所以在 Mac 上，正确玩法是先体验，再缩小规模自己训一个“婴儿模型”。真想完整跑 2 小时，就租一张显卡。

三条路，从易到难

A. 和作者训好的模型聊天约 10 分钟
不训练，只下载成品试用，先看看 6400 万参数的小模型能聊成什么样。
B. 在 Mac 上从零训一个婴儿模型约 50 分钟
只用一小份数据，亲眼看着它从乱码变成“有点像话”。这一步最能学到东西。
C. 租一张显卡，完整复现2 小时以上 · 要花钱
想要一个真正能对话的、自己训的模型，走这条。我没实际租过，下面只写大致做法。

准备：下载代码，装环境

打开“终端”App，一条一条复制粘贴，回车。每条跑完再贴下一条。

1
把代码下载到桌面：
cd ~/Desktop
git clone --depth 1 https://github.com/jingyaogong/minimind
cd minimind
2
建一个独立的 Python 环境。你电脑自带的 Python 是 3.9，太旧了，这条命令会自动下载 3.11，不影响系统：
uv venv --python 3.11 .venv
source .venv/bin/activate

运行完，命令行开头会多出 (.venv)。以后每次新开终端窗口，都要先 cd ~/Desktop/minimind 再 source .venv/bin/activate。

3
装依赖（用阿里云镜像，国内快）。约 1 分钟：
uv pip install -i https://mirrors.aliyun.com/pypi/simple torch==2.6.0 -r requirements.txt
4
补一个坑。不做这步，训练时会报错 pyarrow requires NumPy 2.0：
uv pip install -i https://mirrors.aliyun.com/pypi/simple pyarrow==19.0.1

原因：项目锁定了旧版 numpy 1.26，但默认装上的 pyarrow 太新，两个对不上。换成旧一点的 pyarrow 就好。

A. 和成品模型聊天

5
下载作者训好的模型（122MB）：
modelscope download --model gongjy/minimind-3 --local_dir ./minimind-3
6
开聊。出现提示时输入 1 回车，然后就能打字提问：
python eval_llm.py --load_from ./minimind-3 --device cpu
一定要写 --device cpu。我试过用 Mac 的显卡（--device mps），程序直接崩了，报 mps.matmul ... incompatible dimensions。用 CPU 反而很快，实测每秒 181 个字词。

我问它“北京有什么好玩的公园”，它这样回答（节选）：

1. 北京动物园：位于北京市朝阳区……
2. 故宫博物院：位于北京市朝阳区，是一个以太洪溪为主题的文化中心……
3. 798艺术区：位于北京市中心……

说话很流畅，内容一本正经地瞎编：故宫不在朝阳区，也不是公园。6400 万参数大约是 GPT-3 的 1/2700，能把话说顺已经是它的上限。这就是小模型的真实水平，后面你自己训出来的会更差。

退出：按 Ctrl + C。

B. 从零训一个婴儿模型

7
只下载入门数据的开头 30MB（整份有 1.2GB），再截取前 2 万段文字：
curl -L -r 0-31457279 "https://www.modelscope.cn/datasets/gongjy/minimind_dataset/resolve/master/pretrain_t2t_mini.jsonl" | head -n 20000 > dataset/pretrain_small.jsonl

每一行是一段文章。2 万行大约 15MB。我这边截取用的是一个小脚本，你用的这条 head 命令效果一样，但我没用它实测过。

8
开始训练。用 Mac 的显卡（这里 mps 能用）：
cd trainer
python -u train_pretrain.py --device mps --dtype float32 --epochs 1 --batch_size 16 --num_workers 0 --log_interval 10 --data_path ../dataset/pretrain_small.jsonl
这些参数是什么意思
--device mps用 Mac 的显卡。默认是 CPU，会慢很多
--dtype float32默认的 bfloat16 是给 NVIDIA 显卡用的，Mac 上用 float32 稳
--epochs 1数据只读 1 遍（默认 2 遍）
--batch_size 16一次读 16 段（默认 32，Air 的内存吃不太消）
--num_workers 0不开额外的读数据进程，Mac 上少出问题
-u让进度马上显示出来，不然屏幕会好几分钟没动静

屏幕会一行行刷进度。重点看 loss，它代表“猜下一个字猜错的程度”，越小越好：

Epoch:[1/1](10/1250), loss: 8.4011 ... epoch_time: 30.0min
Epoch:[1/1](50/1250), loss: 7.4694 ... epoch_time: 38.0min
……
Epoch:[1/1](1250/1250), loss: 5.1407 ... epoch_time: 0.0min

(10/1250) 是进度，epoch_time 是预计还剩多少分钟。我这次总共用了约 48 分钟，loss 从 8.4 降到 5.1。训练时电脑会发烫，属于正常现象，这段时间别跑别的重活。

中途断了也不怕：程序每 1000 步自动存一次档。在原命令后面加上 --from_resume 1 再运行，就会从存档处接着训。我这次中途就断过一次，是这样接上的。

9
训完的模型存在 out/pretrain_768.pth。回上一层，跟它说话：
cd ..
python eval_llm.py --weight pretrain --device cpu

输入 1，再打一句话的开头。预训练出来的模型还不会“回答问题”，只会顺着你的话往下接。我给它开头“北京的秋天”，它接了：

是人是由一个亮。天是哪里，这个鸟和天空的。好的，请给我推荐一个句子。这个句子：这首诗中，在树头了，它就来……

字认识，标点会用，甚至学会了“好的，请给我……”这种对话腔，但整句不通。只读了 15MB 文字、训了 50 分钟，就这个水平。把它和第 6 步的成品对比，差距就是“1.2GB 数据 × 2 遍 + 对话训练”带来的。

C. 想完整跑一遍：租显卡

作者的“3 块钱”是租一张 RTX 3090 跑 2 小时的钱。国内有按小时租显卡的网站（比如 AutoDL），大致步骤：

  1. 注册、充值，租一台带 RTX 3090 或 4090 的机器，系统选带 PyTorch 的镜像。
  2. 在网页终端里重复第 1、3 步（显卡机器上不用第 2、4 步，也不用写 --device）。
  3. 下载完整的 pretrain_t2t_mini.jsonl 和 sft_t2t_mini.jsonl 放进 dataset/，依次运行 train_pretrain.py、train_full_sft.py。
  4. 用完马上关机，不然一直计费。

这一段我没实际操作过，价格和界面以网站为准。真要租的时候叫我，我陪你一步步弄。

想再深一点：读代码从哪开始

这个项目最值钱的是代码短，能一行行读懂。推荐顺序：

  1. model/model_minimind.py：模型本体，三百来行。先看 Attention（注意力）和 FeedForward。
  2. trainer/train_pretrain.py：训练循环。核心就是“算 loss → 反向传播 → 更新参数”这几行。
  3. dataset/lm_dataset.py：文字怎么变成数字喂给模型。
